# 辅助营销推荐系统 Recommendation System

本系统旨在帮助财税软件提供商——S公司的客户经理有效地管理客户，为客户推荐公司产品并提供个性化的服务，从而提高企业的市场竞争力。本系统采用B/S架构，前端使用React框架，后端采用Flask框架，可视化利用Echarts工具。
The system aims to assist the customer managers of S Company, a financial and tax software provider, in effectively managing clients, recommending company products to clients, and providing personalized services to enhance the company's market competitiveness. This system adopts a B/S architecture, with the frontend using the React framework, the backend using the Flask framework, and visualization utilizing the Echarts tool.

## Installation
Step-by-step instructions on how to get the project up and running.

```bash
# Clone the repository
git clone https://github.com/hy828/recommendation_system

# Navigate to the project directory
cd recommendation_system

# Install dependencies
npm install
'''
